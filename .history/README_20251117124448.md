# Population genomics and chromosomic inversions in Culex pipiens sensu stricto from southwestern Spain

This repository contains all the scripts and code used for the population genomics project of Culex pipiens from Southwestern Spain, including sequence processing, mapping, variant calling and filtering, population genomics analyses and chromosomic inversions detection.

Notes:
* Environments and servers: During analyses of this project, I worked in three different servers. Some had job management systems (SLURM) and some others not. Also, some of the software used were installed in conda environments, while others were installed globally. The scripts and other code shown here may reflect these differences. That's why I usually use the format *(environment - server)* to indicate where each script/code was run.
* Paths: In the scripts, paths to files and directories have been replaced with generic ones (e.g. /path/to/...).
