# 1. Download and process data from Haba et al., 2025
In order to identify the ecotype of our samples, we downloaded raw sequences from *Cx. pipiens pipiens* and *Cx. pipiens molestus* from [Haba *et al*. (2025)](https://www.science.org/doi/10.1126/science.ady4515) . We used *prefetch* from SRA toolkit to download the data from NCBI SRA and *fasterq-dump* to convert .sra files to fastq files.
A complete list of samples used will be provided hete upon acceptance of the manuscript.

# 2. Mapping and variant calling 
The samples from Haba et al., 2025 were processed using the same pipeline for [mapping](1.sequence_processing_and_mapping.md) and [variant calling](2.variant_calling_and_filtering.md) as ours. The only changes to take into consideration:

* Paths to samples and name of files in the scripts were changed as needed.
* A second run of fastp was done using [fastp2-molestus.sh](scripts/fastp2-molestus.sh) in order to remove overrepresented sequences
```bash
 >overrep1
CTTAAATTCTTAAATTCTTAAATTCTTAAATTCTTAAATTCT
>overrep2
GAATTTAAGAATTTAGAATTTAAGAATTTAGAATTTAAGA)
```
* Variant calling was done sepparetlely for Haba et al. (2025) samples, and the resulting bcf files were merged to ours after [filtering repeats](scripts/filter-snps-invariants.sh) using bcftools *merge*.

```bash
bcftools merge -Ob --threads 4 -o pip1234-mol_3_norep.bcf pipiens1234_3_norep_sorted.bcf molestus_mcbride_3_norep_sorted.bcf
```
The rest of the filtering steps were the same as for our samples.

# 3. Ecotype identification and gene flow
We performed [LD prunning and run PCA](3.Population_strucutre_analyses.md) in the same way as for our samples. We plotted the results and compared the grouping of our samples with those from Haba et al., 2025 in order to identify the ecotype of ours. The 2 clusters identified by admixture analyses also corresponded perfectly with the 2 groups identified as different ecotypes.

12 samples showed intermediate probabilities of belonging to either cluster (40-60%), suggesting they could be hybrids between *Cx. pipiens pipiens* and *Cx. pipiens molestus*. To further explore this, 

This information was used to run [dbRDA analyses](3.Population_strucutre_analyses.md) including ecotype as a numeric variable corresponding to the probability of belonging to cluster 1 (*Cx. pipiens pipiens*).



# Gene flow analyses
(poppy - f3r)
To further explore the possibility of admixture between ecotypes, we performed f3 statistics using [qp3Pop](https://uqrmaie1.github.io/admixtools/reference/qp3pop.html)  from ADMIXTOOLS. We run the analysis using only chromosome 2, as it has no known chromosomic inversions. We pruned the data for LD setting *--indep-pairwise 200 10 0.2*

I then created ecot60-pipiens-f3.eigenstrat.ind file that assign each sample to one group. Groups were defined as *pipiens*, *molestus* and *unassigned* (samples with ecotype ancestry between 40-60% from admixture analyses). The file looked like this:
```
PP1001 U molestus
PP1004 U molestus
PP1016 U molestus
PP1028 U pipiens
PP1033 U pipiens
[...]
```
Where the first column is the sample ID, the second column is a used for sex (not used) and the third column is the group assignment.

For f3 calculations, first, I created a parameter file (par.PLINK2EIGEN) for *convertf*:
```txt
genotypename:   samples.bed
snpname:        samples.bim
indivname:      samples.fam
outputformat:   EIGENSTRAT
genotypeoutname: samples.eigenstrat.geno
snpoutname:      samples.eigenstrat.snp
indoutname:      samples.eigenstrat.ind
familynames:     NO
```
Then, I converted the plink files to eigenstrat format:
```bash
convertf -p par.PLINK2EIGEN
```
This generates the three required EIGENSTRAT files:
*.eigenstrat.geno
*.eigenstrat.snp

Then, we definide the populations we want to check in *trios.txt*:
```txt
molestus pipiens unassigned
pipiens unassigned molestus
unassigned molestus pipiens
```
The format of this file is:
target  source1  source2

So, for each line, *qp3Pop* will compute *f₃(target; source1, source2)*.

Finally, I created a parameter file for *qp3Pop* (par.f3):
```txt
genotypename: chr2_pip_f3_strict.eigenstrat.geno
snpname:      chr2_pip_f3_strict.eigenstrat.snp
indivname:    ecot60-pipiens-f3.eigenstrat.ind
popfilename:  trios.txt
inbreed:      YES
numthreads:   8
```
and we run *qp3Pop*:
```bash
qp3Pop -p par.qp3pop.2ecot60 > qp3pop.2ecot60.out 2> qp3pop.2ecot60.err
```
