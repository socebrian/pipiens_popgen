### 1. Linkage disequilibrium prinning and PCA
 and conventional PCA (culex env on talapas)

In order to perform PCA analyses, first I did linkage disequilibrium prunning to remove SNPs in high LD. I used PLINK. Sometimes it gave back an error caused by some contains on the FORMAT field of the vcf/bcf files. To avoid this, I first removed all FORMAT fields other than GT.
```bash
# first let only GT in format so plink dont freak out
bcftools annotate -x ^FORMAT/GT pipiens123_1_1nBDQF_M.bcf -Oz -o pipiens123_1_filteredGT.vcf.gz
tabix -p vcf stripped.vcf.gz
```
Then I run  <ld-prunning2.sh>. This script prune out SNPs under linkage desequilibrium, recode new vcf without the prunned out sites and then use this new vcf to perform a PCA. I set *--indep-pairwise 50 10 0.5*.

Then I plot the PCA results using ggplot2. The specific code is not included as it is very standard yet very dependent on the specific dataset and the desired aesthetics. I plot based on localities, provinces, habitat (urban vs natural), ecotype (read analyses below) and sex.
